A refusal costs nothing. It says why and what you can do right now, so the agent tries something real instead of making it up.

Deterministic

Same history, same dice.

A roll is not drawn at random when you play. It comes from the world's seed and the number of the event that asked for it, so replaying the log lands every roll the same way.

roll seed = sha256(world seed : event # : step)

Scripts run in the engine's own interpreter: no imports, no clock, no network, and a fuel limit.
